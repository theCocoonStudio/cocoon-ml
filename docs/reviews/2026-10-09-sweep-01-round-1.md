# Sweep 01, dialectical round one (Claude against the apparatus, 2026-10-09)

The rule: two full rounds and two further replications before a number is spoken. Sweep 01 ran nine cells (three table seeds by three model seeds, drift depths 0, 1, 2, 4, 8) in under three minutes; its numbers stay in Claude's log. This round is against what the sweep can show, not what it showed. Each item: the objection, its effect, the fix.

1. **The delta saturates.** `delta` flags whether a resolved ratio moved; every node moves a little at every step, so the flag is near one after a single step and the same for eight. A target that does not vary cannot be read by a probe, and the held-out r² of the probe in this sweep is meaningless for that reason alone, not as evidence about tracking. Fixed: `delta_magnitude`, the mean absolute movement in units of the grain, which keeps growing with drift. Any probe result before this fix is void.

2. **A cut artifact carried a false extension.** `pack_meaning` wrote the whole artifact's extension at a separator even when the length limit had cut the artifact short; the model was asked for the meaning of a string it had not seen. Fixed: an artifact that does not fit whole is dropped. The meaning curves of this sweep at later ranks are void.

3. **The per-position form curve measured padding.** Positions near the end of a context are separators predicting separators; their near-zero loss is not recovery. Fixed: `form_loss_by_rank`, grouped by artifact rank with padding and end-of-artifact targets excluded. The form curves of this sweep are void past the first artifact.

4. **n_eff was read against the wrong table.** The sweep computed n_eff of windows drawn from the drifted table using the training table's amplitudes to filter readings, so a string the old table cannot produce counted as pinning nothing. That is a measure of foreignness, worth having, but it is not what a window pins of the table it came from. Two quantities, one name; the sweep mixed them. Fix in the next sweep: n_eff against the drifted table, and foreignness against the old one reported separately.

5. **The step was a jump.** The bound was one half per table per step against a grain of one eighth: a single step moved shares by more than the resolution, which is the jump the superposition forbids. Fix: the bound at or below the grain per node, so that a step is a step; drift depth then means something.

6. **The model barely learned the table.** One hundred and fifty steps, width four, one layer; the same-table meaning loss in some cells did not move from its start. Recovery under drift cannot be read where there was nothing to recover. Fix: train until the same-table loss stops falling, and report the same-table loss beside every drifted one as the floor.

7. **Too few windows for the probe.** Twelve windows per depth and five features; the held-out r² ranged from strongly negative to moderately positive across seeds, which is a sample-size signature, not a finding. Fix: windows in the hundreds; they cost seconds.

8. **Replication by seed is not replication.** Nine cells on one code path and one size agree on nothing stable; the two replications the rule asks for must vary the table size and the context length, not the seed, or they replicate the artefacts of this size.

Verdict: sweep 01 established that the chain runs and found six defects in the ruler and the run, three fixed in code this round, three to be fixed in the next sweep's design. Nothing in its numbers survives to be spoken, which is what a first sweep is for.
